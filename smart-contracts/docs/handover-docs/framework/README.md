## Main Point

This repo is not single-framework.

It is primarily a Hardhat deploy and test repo with:

- Hardhat Deploy for deployments
- Hardhat as the main TypeScript execution layer
- Foundry integrated for Solidity tests
- Tenderly used for virtual-mainnet workflows
