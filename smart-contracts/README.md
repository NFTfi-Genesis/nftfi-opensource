# NFTfi Protocol

NFTfi V3 smart contracts and development tooling.

## Included

- V3 asset and collection loans
- Refinancing
- NFTfi, NFTfi V2.1, NFTfi V2.3, Arcade, Blend, and Gondi refinancing adapters
- Mainnet deployment artifacts and compiler inputs
- Hardhat and Foundry tests
- Deployment and verification scripts
- CI configuration

## Mainnet

[`mainnet-contract-manifest.json`](mainnet-contract-manifest.json) contains the contract inventory, addresses,
deployment transactions, blocks, compiler versions, compiler-input hashes, and artifact paths.

```bash
yarn manifest:mainnet
yarn verify:mainnet-manifest
MAINNET_RPC_URL=https://... yarn verify:mainnet-state
```

The verifier checks manifest/deployment parity, deployment receipts, code, creation bytecode, Hub and Coordinator
configuration, Refinancing, all registered adapters, and recorded pause states.

## Setup

Requirements: Node.js 20, Yarn 1.22, Foundry, and Git submodules.

```bash
git submodule update --init --recursive
yarn install --frozen-lockfile
```

## Development

```bash
yarn build
yarn test:unit
yarn test:foundry
yarn lint
```

Fork tests require `MAINNET_RPC_URL`:

```bash
yarn test:fork
yarn test:foundry:fork
```

## Deployment and verification

```bash
yarn deploy:local
yarn deploy:sepolia
yarn deploy:mainnet
yarn deploy:mainnet-redeploy-refi
yarn verify:mainnet
yarn verify:virtual-mainnet
```

Configuration is documented in [`.env.example`](.env.example). Operational procedures are in
[`docs/handover-docs/operations`](docs/handover-docs/operations/README.md).

Only Mainnet deployment artifacts are committed. Local, testnet, and virtual-mainnet artifacts are generated by the
deployment tooling and remain untracked.
